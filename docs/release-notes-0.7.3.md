## 一句话

**侧栏按照「项目 / 会话」重新组织，输入区那一栏精简掉，贴图与读历史的手感修好。** 另有一处权限显示与实际执行不一致的缺陷修正。

## 1. 侧栏：项目 / 会话两段（照 DAWN 的模型）

- **项目 = 用户指定的文件夹工作区**，「会话 = 没有文件夹的临时对话」；
- 项目段显示名称与会话数，可折叠、可展开、可在该项目里新建会话；
- 会话段是临时会话（落在 `%APPDATA%/oh-my-coding-pi/scratch`），不混进项目；
- 两段都支持**折叠**（状态记住），段头右侧是「多选」；
- **多选**：项目 → 移出列表（只改表，不动磁盘）；会话 → 归档 / 删除（删除进各自工作区的回收站，当前会话会跳过）。

`workspaces.json` 会自动从老的 `recent` 迁移出 `projects` 表，**不改动任何会话文件**。

## 2. 删掉输入框上方那一栏，预算下沉

原来输入框上方有一行 `$成本 / %ctx / tok / 3U·8A / session·day / 权限pill`，与底部状态栏重复。现在整行删除，**预算挪到底部状态栏**（成本旁边），token 总数与消息计数不再显示（数据仍在）。

## 3. 贴图：能连贴多张，输入框不再被挤窄

- 根因一：`.composer` 是两列网格，附件条抢了第一列，输入框被挤进窄列、发送按钮掉到下一行 → 附件条/状态条/排队条改为各占一整行；
- 根因二：粘贴是异步的，旧代码在 `await` 之后用**调用时的列表快照**拼新数组，两次粘贴挨得近就互相覆盖（表现就是"只能粘一张"）→ 改成基于最新列表合并、按内容去重，张数/单张/合计三个上限逐条给理由；
- 取值同时读 `clipboardData.items` 与 `files`（有些应用只有 items 有图）；
- 附件条：64px 缩略图、横滚、角标显示大小、`2/4 · 3.2/12 MB` 计数、「＋ 再加一张」；
- 输入框随内容**自动增高** 1–6 行（超过内部滚动）。

## 4. 会话区：回到底部 + 智能粘底

- 右下角「↓」按钮：离开底部时出现，回到底部消失；离开期间来的新消息以角标计数；
- 更关键的是**不再无条件贴底**：只有"本来就在底部"时才自动跟随。以前流式输出会把视图一直拽回底部，往上翻历史根本读不了。

## 5. 修复：两处权限设置不同步

顶栏徽标与「权限」面板改完一边另一边不动，原因是它们各存一份本地状态、只在挂载/点开时读一次，主进程也没有推送。现在：

- 新增 `permission:changed` 广播，两处 + 状态栏同时更新；
- **界面显示的档 = 真正拦截用的档**（两者以前是两个来源）；
- 跨工作区的会话按**它自己所在工作区**读权限档（以前读当前视图的 meta，读不到就回落默认）；
- 「设为新会话默认」做成常驻（记住上次勾选），并在两处显示「当前默认：X」。

## 升级说明

覆盖安装即可。`workspaces.json` 自动迁移（新增 `projects` 段），首次打开会创建 `%APPDATA%/oh-my-coding-pi/scratch`。会话文件、`.omcp/`、审计、密钥、插件开关都没有变化。
