# v1 范围与完成定义

- 版本：v1.0（P0 结束时冻结）
- 日期：2026-11-11
- 适用范围：P1–P4
- 变更规则：任何范围变更必须同时更新本文件与 `docs/decisions.md`，否则不进入迭代

---

## 1. 产品定位

面向单个科研工作者的本地桌面工具：在 Electron 界面里与 pi 对话，用常驻 Python/R 内核做分析、出图，所有危险操作经过审批。

不是通用 IDE，不是团队协作平台，不是云端服务。

---

## 2. 用户与核心场景

**用户**：需要反复做“读数据 → 统计/建模 → 出图 → 写结果”的科研人员。

**核心场景**

1. 打开一个项目目录，pi 读取 `AGENTS.md` 与数据文件。
2. 用自然语言描述分析，pi 调 `run_code` 在常驻内核里执行。
3. 图直接显示在对话/笔记本里，可继续修改。
4. 危险命令（删除、提权、外网脚本）弹出四选项审批。
5. 关掉应用再打开，会话与内核状态符合预期。

## 3. v1 做什么

### 3.1 工作区

| 能力 | 说明 |
|---|---|
| 打开目录 | 选择项目根，路径存绝对路径 |
| 项目约定 | 读取 `AGENTS.md`；`.omcp/` 存会话、日志、策略、审计 |
| 目录骨架 | `data/raw`、`data/processed`、`analysis/scripts`、`analysis/notebooks`、`results/{tables,models,reports}`、`figures/` |
| 工作区信任 | 未信任不加载项目级扩展/设置 |

### 3.2 对话

| 能力 | 说明 |
|---|---|
| 流式回复 | 文本增量渲染；工具调用卡片 |
| 工具状态 | 待审批 / 执行中 / 完成 / 失败 |
| 停止 | 乐观停止 + 3 秒未 settle 时强制终止并恢复会话 |
| 会话 | 列表、恢复、重命名、树、fork/clone、导出 HTML |
| 模型 | 切换 provider/model，显示成本与上下文占比 |
| 输入 | 多行、图片粘贴、`@` 文件引用（P1 可先不做 @） |

### 3.3 笔记本

| 能力 | 说明 |
|---|---|
| Python 内核 | 常驻；变量跨轮保留 |
| R 内核 | 常驻；P2 接入 IRkernel |
| 输出 | stdout/stderr 流式；异常 traceback |
| 图片 | matplotlib PNG 内嵌；同时保存到 `figures/` |
| 控制 | 中断、重启、清空输出 |
| 环境 | 探测工作区 venv/renv，再找系统解释器；可手动指定 |

### 3.4 权限

| 能力 | 说明 |
|---|---|
| 策略 | 工具白名单、路径 glob、命令正则、runCode 规则 |
| 审批 | 仅本次 / 本会话 / 总是允许 / 拒绝；超时默认拒绝 |
| 三档权限 | 自动拦截 / 请求批准 / 完全访问（ADR-049）；会话级覆盖，可设为新会话默认；硬拒清单任何档都拒 |
| 授权存储 | 应用数据目录，按工作区绑定，可撤销、可过期；**不读工作区文件** |
| 审计 | 工具、参数摘要、决策、时间、会话；可导出 |
| 只读模式 | 仅 read/grep/find/ls；内核只读提示 |
| 明示 | 界面固定显示“本机直跑，未沙箱化；权限用于防误操作，不构成安全边界” |

### 3.5 设置与分发

| 能力 | 说明 |
|---|---|
| 设置 | provider/model、密钥（系统安全存储）、内核路径、策略路径、数据目录 |
| 模型服务目录 | 从内置 43 个服务商目录里挑，地址/协议/模型目录内置，只填密钥；连通性探测（0.5.3） |
| 用量统计 | 累计/今日/峰值/连续天数、26 周热力图、按模型占比；口径 `input + output`，不含 cacheRead（0.5.3） |
| 安装 | Windows NSIS，按当前用户安装，无需管理员 |
| 更新 | v1 手动下载安装包；自动更新留到 v1.1 |
| 文档 | 安装、权限说明、已知限制、第三方许可 |

## 4. v1 不做什么

明确排除，避免范围膨胀：

1. 文献检索、MCP、子 agent、团队调度。
2. 技能市场（在线安装与来源校验）、分析路线面板的自动推断。
3. 插件市场与第三方扩展审核。
4. 容器/WSL 隔离（v1.1 再评估）。
5. 多用户、协作、云同步、账号体系。
6. 自动更新、代码签名、遥测。
7. 移动端、Web 端。

浏览器自动化、记忆系统、Office/PDF 原本在本节排除，现改为**分期开放**（见 4.1）：
越界功能不能靠“默认就开”稀释，一律默认关闭，并分批过决策门。

---

## 4.1 分期开放（插件，默认关闭）

| 期 | 内容 | 工具数 | 判据 |
|---|---|---|---|
| P1+P2 | 插件框架 + 记忆 | 3 | 开关能关掉工具（新会话里确实消失）；记忆 3 工具可写可读 |
| P3+P4 | Office 文档（xlsx/docx/pptx/pdf） | 14 | 读 6 类文件不崩；写出文档能被 Office/WPS 打开 |
| P5+P6 | 浏览器（打开/读页/操作/产物） | 15 | 真实页面可开、可点、可截图；体积可接受（ADR-050：复用系统 Edge/Chrome） |

**决策门**：P1+P2 完成后停下来评估——开关模型是否好用、记忆是否真的被用到。
不通过就停在框架 + 记忆，不做 Office 与浏览器（省 15 天）。

约束（ADR-044/045/046）：整包 + 分族开关；改动对**下一段新会话**生效，不影响正在进行的会话；
插件工具写文件照走审批与审计，路径不出工作区；记忆不落工作区（存应用数据目录）。

## 5. 完成定义（DoD）

v1 必须同时满足：

| 编号 | 定义 | 判定方式 |
|---|---|---|
| D1 | 可演示 | 5 条验收用例全部跑通 |
| D2 | 可恢复 | 强制结束 pi 后重启，能继续原会话，历史不丢 |
| D3 | 可拦截 | 验收用例中的危险命令 100% 被拦，拒绝原因模型能解释 |
| D4 | 可导出 | 图进 `figures/`，表进 `results/tables/`，路径正确 |
| D5 | 可安装 | 干净用户配置下，非管理员安装即可运行 |
| D6 | 成本可见 | 每会话显示 token、金额、上下文占比 |
| D7 | 文档齐 | 安装、权限、已知限制、第三方许可 |

## 6. 五条验收用例

### A1 读数据 → 描述统计 → 箱线图

1. 在工作区放 `data/raw/demo.csv`（含数值列与分组列）。
2. 输入：“读 demo.csv，按组做描述统计，画箱线图。”
3. 期望：
   - `run_code` 被调用；
   - 输出包含均值/中位数/样本量；
   - 对话里出现 PNG；
   - `figures/` 下有对应文件。

### A2 改图后重跑

1. 接 A1，输入：“把字体改成 12，图宽改成 8，重新画。”
2. 期望：
   - 同一内核继续，不重新读数据；
   - 新图替换旧图显示；
   - `figures/` 新增文件，旧文件不删。

### A3 危险命令被拦并解释

1. 输入：“执行 `rm -rf ./data`。”
2. 期望：
   - 弹出四选项审批；
   - 选“拒绝”后命令不执行；
   - 目录仍存在；
   - pi 回复说明被审批门拦截；
   - 审计日志新增一条 `deny`。

### A4 崩溃恢复

1. 进行一轮对话后，任务管理器强制结束 pi 进程。
2. 期望：
   - 界面显示桥接断开；
   - 重启后能恢复最近会话；
   - 已有消息完整；
   - 成本统计不重置。

### A5 导出图与表

1. 输入：“把刚才的统计结果写成 csv，放到 results/tables。”
2. 期望：
   - 文件出现在 `results/tables/`；
   - 内容与界面显示一致；
   - 不写到 `data/raw/`。

## 8. 终止条件

出现以下任一情况，暂停开发并重新评估：

1. 内核在 100 次执行中失败 > 5%，且两次修复后仍不达标。
2. pi 每次升级导致扩展/桥接返工 > 2 天，且无法用适配层隔离。
3. 验收用例发现可绕过审批的高危路径，3 天内无法修复。
4. 8 周内仍无法跑通 A1。
5. 关键依赖（Jupyter/pi/Electron）出现不可接受的许可证或安全事件。
