## 1. 产物：点开就地看，不再跳走

以前点一个产物会切到「文件」页签并强行定位，产物列表随之消失。

- 现在点开是**在产物面板里预览**：图片、CSV/TSV 表格、Markdown（渲染）、其它文本按原文。
- `← 列表` 或 `Esc` 返回，列表滚动位置保留。
- 「在文件页签打开」保留，但变成**主动**选择——想去看目录结构时才点。
- 文件页签的当前目录、滚动、选中**全程不动**。
- 账本里有、盘上没有的文件仍显示「已不存在」，不静默删除。

## 2. 对话：运行中发的话可以选方向

以前运行中按回车会直接插进当前轮，等于永远在打断。

- **Enter** = 排到这一轮后面（排队）；**Ctrl/Cmd + Enter** = 立刻转向。
- 输入框上方出现「待发 · N」：每条可**调整方向**（立刻送达）、**新增会话**（这一轮结束后另起一段）、**全部取回**。
- 取回会把待发文本原样放回输入框，并把对应的气泡从对话里撤掉。
- 队列以 pi 自己的队列为准（`queue_update`），界面不自建一份。

## 3. 会话：列表里不再是一串 01a1e7f8

- 会话标题从**第一条消息**派生：最多 24 字，`@` 路径折叠、URL 只留域名、去掉 Markdown 标记。
- 老会话在列表加载时**懒回填**一次，结果写进 `.omcp/session-meta.json`，重启不重算。
- 同批重名会加 `· 2` 后缀。
- 手动重命名后，自动标题不再覆盖；清空标题可重新生成。
- 列表右侧改显示相对时间（`2m / 3h / 2d`），鼠标悬停看完整路径。
