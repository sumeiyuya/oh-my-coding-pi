## 1. 这是一次彻底的改名

项目改用新名 **oh my coding pi**，并且**不保留任何旧标识**（旧名不进代码、不进仓库、不进历史）：

| 项 | 新值 |
|---|---|
| 显示名 / 安装包 | `oh my coding pi` |
| npm 包 | `oh-my-coding-pi` / `@oh-my-coding-pi/*` |
| 可执行文件 | `omcp.exe` |
| appId | `com.omcp.desktop` |
| 用户数据 | `%APPDATA%\oh-my-coding-pi` |
| 环境变量 | `OMCP_*` |
| 本地存储 | `omcp.*` |

| 工作区元数据 | `.omcp/` |

**换新仓库**：旧仓库只归档、不再维护；新仓库的第一个提交就是 0.6.0，历史里没有旧名字。

## 2. 需要你手动处理的三件事

1. **旧工作区**：老项目的元数据目录（改名前的那个）不会被读取。要保留路线/方案/笔记本，把该目录名改成 `.omcp` 即可。
2. **旧密钥引用**：`~/.pi/agent/models.json` 里若还是旧前缀的 `$…KEY_*` 引用，删掉那个 provider 条目，到「设置 → 补全当前 Provider」重新填一次；应用会按新前缀重新生成。
3. **旧版本**：appId 变了，新安装不会覆盖旧版。请先卸载机器上已装的旧版本，再装这个。

## 3. 功能与上一版一致

改名不改变功能。这版含此前几轮的全部能力：

- 对话与工具循环、工具调用成组折叠（默认收起，点开看逐条）
- 可拖可折叠的三栏布局、右坞四面板、底部状态栏、会话搜索与分组
- Python / R 常驻内核、串行执行、解释器切换确认
- 模型服务：按官方环境变量注入凭据、发送前预检、连接确认对话框
- 三档权限、方案期门（批准绑定内容）、审计与持久授权
- 科学计算扩展、浏览器插件、记忆
