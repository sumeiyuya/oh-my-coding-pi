## 1. 文件区：树形折叠（参考 DAWN）

右坞「文件」页从「一次只看一层、点目录整页替换」改成树形：

- 文件夹可逐级展开（收起 ▸ / 展开 ▾），每级缩进 16px；根节点显示工作区名。
- 点文件在下方预览，**树留在原位**、选中行高亮；预览左上角 `×` 关闭。
- 按目录**懒加载**，展开时才请求 `fs:list`；展开过的目录在组件内缓存。
- **键盘导航**：`↑/↓` 移动，`Home/End` 首尾，`→` 展开/进入子项，`←` 收起/回父级，`Enter/Space` 打开。
- **展开状态按工作区持久化**（`localStorage["omcp.fileTree.<短哈希>"]`，最多 200 条）；切页签、重启应用都保留，换工作区才重置。
- 产物面板的「在文件中显示」改为逐级展开父目录后选中并预览。
- 边界：空目录显示「空目录」，目录读失败显示「读不到」，超过 1000 条提示截断，符号链接标 `↗`。

## 2. 顶栏：控件栏贴会话区左侧

- 请求批准 / 上下文 / 模型 / 推理 / READY 从右对齐改为**贴会话区左缘**，右侧留白。
- 面板按钮仍固定在窗口最右，两者互不挤压。

## 3. 面板按钮：真正固定在窗口最右

上一版按钮在会话区顶栏里，开合右坞时会跟着移动一个坞宽。现在改为：

- 顶栏从 `.main` 移出，横跨「主区 + 右坞」两列；右坞从顶栏下方开始。
- 顶栏高度 48px，与侧栏「oh my coding pi / v0.6.7」底边对齐。
- 实测：面板开、关两种状态下，按钮距窗口右缘都是 **16px**（开合相差 0）；右坞页签不再被按钮挤压。
- 修饰：右拖拽条从顶栏下方开始；窄窗 <820px 顶栏与主区回到单列，右坞与按钮一起隐藏。
