## 1. 输入框：把本机文件带进对话

输入框左侧新增 `＋`（添加内容），菜单三项：

- **上传文件**：任意文件；
- **上传图片**：图片作为附件发送；
- **上传数据**：csv / xlsx / parquet / RDS 等，作为可引用的数据文件。

落位规则：

| 文件位置 | 行为 |
|---|---|
| 工作区内、路径不含空白 | 不复制，插入 `@相对路径 ` |
| 工作区外，或路径含空白 | 复制到 `<工作区>/.omcp/uploads/<日期>/`，再插入 `@` 引用；原文件保留 |
| 图片 | 不插路径，加入附件缩略图 |

- 文件/数据**不设应用层限额**；复制前检查磁盘剩余空间，流式复制并显示进度，可取消；超过 1 GB 只做二次确认。
- 图片保留 **4 张 / 单张 4 MB / 总计 12 MB** 的安全上限（base64 与模型输入约束）。
- 拖拽普通文件走同一落位；粘贴/拖拽图片保持原行为。
- 审计写 `.omcp/logs/audit.jsonl`：只记数量、路径、引用/复制方式，不记内容、不记大小；图片只记名称。

## 2. 工作区侧栏：工作区为树根

- 顶部主按钮「＋ 新建任务」。
- 工作区改为可折叠树：当前工作区展开，会话直接挂在下面；最近工作区折叠显示会话数。
- 会话行 `⋯`：重命名 / 置顶 / 归档 / 克隆 / 导出 / 在树中查看 / 删除。
- 置顶写 `session-meta.pinned`，排在组内最前。
- 「树」从行内菜单打开，不再占顶部页签。
- 底部「已归档 N」切换归档视图；归档数直接来自 `session-meta`。
- 搜索同时过滤工作区名与会话标题；展开分组状态落盘。
- 按确认**不做多选 / 批量归档**；不做全文内容搜索。

## 3. 布局：左栏常驻，右坞 DAWN 化

- 删除「收起左栏」按钮与折叠状态；左栏始终占一列，宽度仍可拖（240–420）。
- 删除「收起右坞」按钮，改为顶栏「面板：X」开关 + 坞内标签 `⋯` / `×`。
- 关闭右坞后**不保留 40px 图标条**，主区占满；再点「面板」恢复上次标签。
- `Ctrl+J` 保留为右坞开合；`Ctrl+B` 失效；`Ctrl+Alt+1–4` 仍切面板。

- 最近工作区展开只显示“切换到此工作区”，不列出该工作区的会话；会话列表只加载当前工作区。
- 删除会话是移到 `.omcp/trash/sessions/`，当前会话拒绝删除；回收站没有清理入口。
- 会话行 `⋯` 菜单为绝对定位，靠近列表底部时可能被滚动容器裁切。

- 原生文件/图片对话框与真实鼠标拖拽未在当前环境手测；核心落位与审计由 `uploadcheck` 覆盖。
