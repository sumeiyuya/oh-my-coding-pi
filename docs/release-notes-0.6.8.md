## 1. 对话区排版重做

- **回答占满会话区**：助手回答不再被 820px 限制。
- **按内容自适应**：用户消息与回答的气泡宽度随内容收缩（用户最长 820px，回答最长占满会话区），短消息不再撑成整行大卡片。
- **助手回答去气泡**：透明背景、无边框、无内边距，正文直接落在会话区；代码块/表格/引用保留自身底色。
- **工具调用去气泡**：工具组与单条工具卡片改为纯文本行，悬停仍有浅色底。
- **删除用户「你」标签**：只保留右对齐的输入气泡。
- **π 身份标识**：24×24 π 徽标 + 17px 加粗 `pi`（与 h2 同大）。
- **字号统一**：用户消息与回答都是 15px，行高 1.5；h2 17 / h3 16 / h4 15；行内代码 13px。
- **更紧凑的排版**：段落 5px、列表项 1px、标题 10/4px。
- **消息间距**：用户→回答 18px，回答→下一条 22px。

## 2. Python / R 语言徽标

- `run_code` 行前显示 `Py` / `R` 徽标（17×17，R 为官方蓝底白字）。
- 覆盖：单条工具卡片、工具组每行与组头、笔记本 cell 头、右坞「运行」页内核状态行。
- 判定：参数 `language: "r"` 为 R；缺省为 Python（工具默认）；参数截断/非法 JSON 不显示，不猜；`bash` 等不显示。

## 3. 错误提示：只说人话，原文折叠

- 主行只有**结论 + 一句原因**（如「连不上模型服务 · 网络请求超时」），技术原文收进「查看原始错误」折叠区。
- 折叠区里的 `attempted addresses: 2606:...`、IPv6 地址替换成「（地址已隐藏）」。
- 自动重试时只显示「正在重试 · 第 1/3 次，2 秒后重试」，不再闪原始报错。
- 对话里的系统消息也只写标题 + 建议。
- 完整原文仍写入 `logs/app.jsonl` 与诊断包。

## 4. 深色模式：设置/权限等浮层跟随主题

- 修复深色下设置面板仍是白卡片、部分文字看不清的问题。
- 设置 / 权限 / 审批 / 路线 / 技能 / 模型注册表 / 用量 / 内核设置全部改用主题变量。
- 新增 `--ok-text / --danger-text / --warn-text`，浅色保持原深色、深色用亮色。
- 输入框/下拉框补 `color: var(--text)`（深色下不再黑字深底）。
- 对比度扫描：深色设置 220 项、权限 199 项、路线 32 项、技能 15 项，低于 4.5:1 的均为 0。
