# 修改 1：权限弹层文字布局

- 日期：2026-11-22
- 范围：权限三档弹层（`PermissionPill`）与顶栏模型触发器
- 状态：已完成，未发布

## 现象

权限弹层里的三档说明与底部边界说明**不换行**，文字一直向右排，超出弹层边框后被截断：

- 「完全访问权限」的描述只显示到「只拦硬拒…」；
- 底部「硬拒清单（sudo、删到主目录 / 系统目录、带凭据出网、强推）…」只显示前半句；
- 顶栏的「（未选择模型）」也被压缩成「（未选择模…」。

## 原因

1. `.bar-right > * { white-space: nowrap; }` 是为了顶栏按钮不竖排，但权限弹层是 `.perm-pill` 的子元素，`nowrap` 被继承进弹层，描述与说明都不再换行。
2. `.perm-pill-item` 是 grid（`20px 1fr 16px`），中间列没有 `min-width: 0`，长文本会把列撑开。
3. 弹层宽 300px，在深色设置下描述一行放不下，进一步加重溢出。
4. 未选择模型时文案「（未选择模型）」比可用空间长，触发省略号。

## 修复

`apps/renderer/src/index.css`：

- `.perm-pill-menu` 显式 `white-space: normal`，并加 `max-height: calc(100vh - 96px)` + 纵向滚动。
- 宽度 300 → **320px**；`max-width: calc(100vw - 24px)` 保留。
- `.perm-pill-item-text { min-width: 0; }`，让 grid 中间列可以收缩。
- `.perm-pill-item-desc` / `.perm-pill-note` 加 `overflow-wrap: anywhere`。
- `.perm-pill-trigger` 保持 `white-space: nowrap`（顶栏按钮仍是一行）。

`apps/renderer/src/ModelPicker.tsx`：

- 未选择模型时显示「选择模型」，完整标题仍放在 `title` 提示里。

## 验证

- 用真实 `index.css` + 弹层 DOM 做静态预览（放在 `.bar-right` 的 `nowrap` 继承环境下）：
  - 三档描述全部换行，无横向溢出；
  - 底部说明完整显示四行；
  - 勾选标记不再与文字重叠。
- `pnpm --filter @oh-my-coding-pi/desktop typecheck` 通过。
- `pnpm --filter @oh-my-coding-pi/desktop build` 通过。
- 真机：dev 应用热更新后打开权限弹层确认（建议在浅色/深色各看一次）。
